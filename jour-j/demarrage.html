Votre démarrage en six étapes

Une dizaine de minutes, sans rien installer : un navigateur et un compte GitHub suffisent. Cochez au fur et à mesure.

0 sur 6

D'abord, votre squad

Choisissez celle que l'animation vous annonce.

  1. Connectez-vous à GitHub dans ce navigateur

    Ouvrir GitHub

  2. Ouvrez le Codespace de votre squad

    Choisissez d'abord votre squad

    Cliquez sur Create codespace. Acceptez les fenêtres qui s'ouvrent.

  3. Attendez le message « Welcome to Codespaces! »

    Environ 2 minutes, dans le terminal en bas. Ne tapez rien avant.

  4. Connectez Claude avec le compte qu'on vous a remis

    Cliquez dans le terminal et tapez :

    claude auth login

    Ouvrez le lien affiché dans le terminal (Cmd + clic, ou Ctrl + clic sous Windows), connectez-vous, copiez le code obtenu, collez-le dans le terminal, puis Entrée. C'est bon quand il affiche « Login successful ».

  5. Ouvrez Claude et tapez /bienvenue

    Dans la barre verticale tout à gauche, cliquez sur l'icône Claude (une étoile), puis sur Nouvelle session (New session). Dans la zone de saisie du panneau qui s'ouvre, tapez :

    /bienvenue

    Ignorez le panneau « Créer avec des assistants » qui s'ouvre à droite : c'est Copilot, pas Claude.

  6. Tapez la phrase « À vous », puis /coach

    Perdu ? Tapez /coach : il dit quoi faire ensuite.

    L'écran de votre squad s'ouvre tout seul dans le Codespace : il montre où en est la squad, la prochaine étape et la phrase à taper. Il est trop petit à cet endroit : ouvrez-le dans un onglet à part (onglet Ports en bas, ligne 4000, icône globe).

Bloqué plus de 2 minutes ? Levez la main : l'animation vient vous aider.

Si quelque chose ne va pas

« claude » : commande introuvable

Ouvrez un nouveau terminal (bouton + du terminal) et retapez la commande.

Claude dit « Not logged in » ou demande de se connecter

Le code de la page de connexion n'a pas été collé dans le terminal. Collez-le, puis Entrée. Si la page a expiré : Ctrl + C dans le terminal, puis relancez claude auth login.

/bienvenue n'apparaît pas quand je tape /

Fermez le panneau Claude et ouvrez une Nouvelle session. Toujours rien : levez la main.

J'ai fermé l'onglet du Codespace

Retrouvez-le sur github.com/codespaces. Ne recliquez pas le bouton de l'étape 2 : cela en créerait un deuxième.

Rien ne s'affiche dans le terminal après 10 minutes

Vous avez sans doute rouvert un ancien Codespace. Supprimez-le sur github.com/codespaces, puis recréez-le avec le bouton de l'étape 2.
